Vector the Game

Susun kartu vektor sampai jumlahnya tepat di target.

Level 1/6Skor 0

Titik hitam = start (0,0). Bintang = target. Tiap kartu dipakai maksimal sekali; panah disambung ujung ke pangkal. Jumlah semua komponen x dan y harus sama dengan target.

Simpan skor lu ke papan peringkat.

Papan peringkat

    Papan ini tersimpan di browser (localStorage). Untuk tugas, bagian simpan/ambil skor bisa disambungkan ke Google Sheets atau Firebase lewat fungsi saveScore() dan loadScores() di kode.
